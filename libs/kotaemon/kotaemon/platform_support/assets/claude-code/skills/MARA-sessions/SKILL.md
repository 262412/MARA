# MARA Sessions

## Scope

Use this skill when the user wants to inspect saved top-level MARA sessions.

## Command

- `MARA sessions`

## Relevant Parameters

- `--json` emits structured output

Use `MARA resume <session-id>` to reopen a saved session.

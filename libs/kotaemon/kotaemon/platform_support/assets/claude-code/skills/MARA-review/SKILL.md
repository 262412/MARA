# MARA Review

## Scope

Use this skill when the user wants read-only review, feedback, or inspection of a slide deck through the top-level `MARA review` command.

## Command

- `MARA review`

## Focus

Use this for critique, structure checks, and readiness reviews without mutating the deck.

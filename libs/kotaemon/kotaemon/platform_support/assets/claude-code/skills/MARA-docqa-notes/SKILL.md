# MARA DocQA Notes

Use this skill for notebook-style notes attached to a saved MARA DocQA conversation.

Common commands:

- `MARA docqa notes list <conversation-id>`
- `MARA docqa notes add <conversation-id> --title "Key point" --text "Evidence-backed note"`
- `MARA docqa notes save-answer <conversation-id> --title "Saved answer"`
- `MARA docqa notes convert-source <conversation-id> --note <note-id>`

Run `MARA docqa sessions` first if the conversation id is unknown.

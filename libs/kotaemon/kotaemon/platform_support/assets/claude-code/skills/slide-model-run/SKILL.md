# Slide Model Run

## Scope

Use this skill to run one routed completion through the `slide` product CLI.

## Command

- `slide model run --prompt "..." --model <name> --provider <provider> --config modelcli.yml --dry-run`
- `slide model run --prompt "..." --model <name> --provider <provider> --config modelcli.yml`

## Focus

Prefer `--dry-run` first for new model aliases, providers, or config files.

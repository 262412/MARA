# MARA Extract

## Scope

Use this skill when the user wants to extract slide content, attachments, or other assets through the top-level `MARA extract` command.

## Command

- `MARA extract`

## Focus

Use this for content harvesting and artifact extraction when the goal is to reuse material outside the deck.

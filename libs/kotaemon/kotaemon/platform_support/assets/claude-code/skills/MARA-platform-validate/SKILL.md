# MARA Platform Validate

## Scope

Use this skill to validate platform support bundles or installed targets through the `MARA` product CLI.

## Command

- `MARA platform validate`
- `MARA platform validate --platform codex`
- `MARA platform validate --platform claude-code`
- `MARA platform validate --platform codex --installed`
- `MARA platform validate --platform claude-code --installed`

## Focus

Run bundle validation before publishing and installed validation after `MARA platform install`.

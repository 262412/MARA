# Slide

## Scope

Use this skill when the user needs the top-level `slide ...` workflow and the request spans multiple slide actions.

If `slide` is not on `PATH`, install the slide CLI first:

- `pip install slide-cli`
- or install the packaged runtime with the `slide` extra

# Slide Platform Validate

## Scope

Use this skill to validate platform support bundles or installed targets through the `slide` product CLI.

## Command

- `slide platform validate`
- `slide platform validate --platform codex`
- `slide platform validate --platform claude-code`
- `slide platform validate --platform codex --installed`
- `slide platform validate --platform claude-code --installed`

## Focus

Run bundle validation before publishing and installed validation after `slide platform install`.

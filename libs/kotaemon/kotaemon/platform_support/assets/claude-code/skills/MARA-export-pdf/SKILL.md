# Slide Export PDF

## Scope

Use this skill when the user wants to produce a PDF export from a slide deck through the top-level `MARA export-pdf` command.

## Command

- `MARA export-pdf`

## Focus

Use this when the deck content is settled and the goal is a PDF artifact.

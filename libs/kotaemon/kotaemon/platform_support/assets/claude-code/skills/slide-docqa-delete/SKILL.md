# Slide DocQA Delete

Use this skill when the task is to remove one or more indexed slide files from the shared DocQA collection.

Examples:

- `slide docqa delete file-id`
- `slide docqa delete file-id-1 file-id-2`

Helpful follow-up commands:

- `slide docqa files`
- `slide docqa sessions`

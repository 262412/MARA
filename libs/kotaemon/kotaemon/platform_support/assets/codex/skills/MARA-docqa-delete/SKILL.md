# MARA DocQA Delete

Use this skill when the task is to remove one or more indexed MARA files from the shared DocQA collection.

Examples:

- `MARA docqa delete file-id`
- `MARA docqa delete file-id-1 file-id-2`

Helpful follow-up commands:

- `MARA docqa files`
- `MARA docqa sessions`

This removes indexed files; it does not delete saved conversations. Verify the requested file IDs and list indexed files afterward.

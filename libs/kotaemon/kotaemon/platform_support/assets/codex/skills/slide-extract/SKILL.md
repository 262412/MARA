# Slide Extract

## Scope

Use this skill when the user wants to extract slide content, attachments, or other assets through the top-level `slide extract` command.

## Command

- `slide extract`

## Focus

Use this for content harvesting and artifact extraction when the goal is to reuse material outside the deck.

# MARA DocQA Chat

Use this skill for interactive, multi-turn MARA DocQA work.

Examples:

- `MARA docqa chat --file deck.pptx`
- `MARA docqa chat --reasoning mara --agent-mode thorough --artifact quiz`

If the user already has a saved conversation, prefer `MARA docqa resume`.

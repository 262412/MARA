# Slide Export PDF

## Scope

Use this skill when the user wants to produce a PDF export from a slide deck through the top-level `slide export-pdf` command.

## Command

- `slide export-pdf`

## Focus

Use this when the deck content is settled and the goal is a PDF artifact.

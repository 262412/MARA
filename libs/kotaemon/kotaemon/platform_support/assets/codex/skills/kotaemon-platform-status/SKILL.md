# Kotaemon Platform Status

## Scope

Use this skill to inspect which platform components are installed in a target directory.

## Command

- `kotaemon platform status --platform codex`
- `kotaemon platform status --platform claude-code`

## Focus

Use `--target-dir <path>` when validating a non-default `.codex` or `.claude` directory.

# Slide Inspect

## Scope

Use this skill when the user wants a read-only structural inspection of a slide deck through the top-level `slide inspect` command.

## Command

- `slide inspect`

## Focus

Use this for deck structure checks, slide inventory review, and other non-destructive inspection tasks.

# Slide Platform Status

## Scope

Use this skill to inspect installed Codex or Claude Code support assets through the `slide` product CLI.

## Command

- `slide platform status --platform codex`
- `slide platform status --platform claude-code`

## Focus

Use `--target-dir <path>` when validating a non-default `.codex` or `.claude` directory.

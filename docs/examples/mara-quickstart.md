# MARA quickstart: Project Cedar

This is fictional demonstration material for testing document import and
question answering. It does not report an experiment or a real organization's
plans.

## Pilot collection

The Project Cedar pilot contains 12 reports: 8 PDFs and 4 presentations.
The reports are reviewed in three stages: import, validation, and evidence
review.

## Review procedure

During import, record each source's filename and check that indexing finishes.
During validation, ask a question whose answer is stated in the source.
During evidence review, compare the answer with its cited passage before saving
a note or generating a study guide.

## Completion criterion

The pilot is complete when all 12 reports have been reviewed and each retained
answer has supporting source material. An application starting successfully
does not, on its own, satisfy this criterion.

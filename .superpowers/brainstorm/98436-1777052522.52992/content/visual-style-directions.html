Slides / Kotaemon UI 风格方向

这是一个文档 QA、文件管理、页面预览、知识图谱和模型设置都很重的工作台。重点不是“炫”，而是让用户长时间阅读、检索、对照引用和管理配置时保持清楚、可信、低疲劳。

Slides

A. 精准研究工作台

浅色中性底，深墨文字，青绿作为主操作，蓝色用于链接和引用。最适合默认方案：专业、清楚、适合长时间阅读和管理。

推荐默认 高可读性 低学习成本
Slides

B. 深色知识图谱实验室

深色底加荧光青绿和天蓝，知识图谱很有氛围。适合作为暗色主题，但默认使用会让文档阅读和设置页更累。

沉浸感强 图谱突出 默认风险较高
Slides

C. 温和阅读资料库

温暖纸张底、森林绿和琥珀强调。适合偏“个人知识库 / 阅读器”的产品气质，但对企业管理和模型设置会略显软。

亲和 阅读感 工程感较弱
我的初步建议：以 A 做默认方向，保留 B 作为暗色主题的灵感，把 C 的“阅读舒适度”借到文档预览和引用卡片里。这样不会把整个产品做成单一深色或单一蓝绿色，也更贴合你的项目：RAG 工作台、文档预览、知识图谱和 CLI/Web 共用的专业工具。

# MARA Inspect

## Scope

Use this skill when the user wants a read-only structural inspection of a slide deck through the top-level `MARA inspect` command.

## Command

- `MARA inspect`

## Focus

Use this for deck structure checks, slide inventory review, and other non-destructive inspection tasks.

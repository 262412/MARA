# MARA DocQA Sources

Use this skill for include/exclude source selection in a saved MARA DocQA conversation.

Common commands:

- `MARA docqa sources list <conversation-id>`
- `MARA docqa sources select <conversation-id> --file report.pdf --file deck.pptx`
- `MARA docqa sources guide <conversation-id>`

Run `MARA docqa files` first when file ids or exact indexed names are needed.

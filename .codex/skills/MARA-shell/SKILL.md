# MARA Shell

## Scope

Use this skill when the user needs to execute shell commands from the top-level `MARA shell` command.

## Command

- `MARA shell`

## Focus

Use this for command execution, environment inspection, and other shell-driven workflows. Prefer non-destructive inspection first when a command could change files or state.

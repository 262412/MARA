# Slide Read Slide

## Scope

Use this skill when the user wants to inspect the contents of one or more slides through the top-level `slide read-slide` command.

## Command

- `slide read-slide`

## Focus

Use this for slide-level text inspection, notes review, and other read-only content lookup tasks.

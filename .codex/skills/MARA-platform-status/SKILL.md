# MARA Platform Status

## Scope

Use this skill to inspect installed Codex or Claude Code support assets through the `MARA` product CLI.

## Command

- `MARA platform status --platform codex`
- `MARA platform status --platform claude-code`

## Focus

Use `--target-dir <path>` when validating a non-default `.codex` or `.claude` directory.

# Kotaemon Platform Validate

## Scope

Use this skill to validate platform support bundles or installed targets.

## Command

- `kotaemon platform validate`
- `kotaemon platform validate --platform codex`
- `kotaemon platform validate --platform claude-code`
- `kotaemon platform validate --platform codex --installed`
- `kotaemon platform validate --platform claude-code --installed`

## Focus

Run bundle validation before publishing and installed validation after `kotaemon platform install`.

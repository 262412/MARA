# Slide DocQA Resume

Use this skill for reopening a saved slide DocQA conversation.

Important distinction:

- `slide resume` stays reserved for the phase-1 slide-session workflow.
- `slide resume-docqa` is the top-level alias for `slide docqa resume`.

Examples:

- `slide resume-docqa 12345`
- `slide docqa resume 12345`

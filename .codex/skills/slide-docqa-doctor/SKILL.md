# Slide DocQA Doctor

Use this skill for a quick runtime readiness check before slide DocQA work.

Examples:

- `slide doctor`
- `slide docqa doctor`

If the runtime is packaged, the common first steps are `kotaemon app init` and `kotaemon app doctor`.
